# 거래방 시각 개선 설계

## 목표

거래방에서 내 메시지와 상대 메시지를 즉시 구분할 수 있게 하고, 거래 완료 상태와 입력 영역이 전체 화면 배경 및 간격 체계와 자연스럽게 어우러지도록 개선한다.

## 메시지 말풍선

- 모든 메시지는 배경색이 있는 말풍선으로 표시한다.
- 내 메시지는 기존 진한 초록색과 흰색 글자를 유지하고 오른쪽에 배치한다.
- 상대 메시지는 연한 베이지·회색 계열 배경과 진한 글자를 사용하고 왼쪽에 배치한다.
- 발신자, 본문, 전송 시각은 같은 말풍선 안에 유지한다.

## 거래 완료 상태

- 현재의 흰색 패널을 페이지 배경과 어울리는 연한 녹색 계열 카드로 변경한다.
- 제목과 참여자 상태 사이의 여백을 늘린다.
- 각 참여자는 이름과 상태가 포함된 칩으로 표시한다.
- 진행 중과 완료 상태는 색상과 문구로 구분한다.

## 간격

- 헤더, 완료 상태 카드, 메시지 목록, 입력창, 거래 완료 버튼 사이의 세로 간격을 확대한다.
- 카드 내부 여백도 늘려 요소가 테두리에 붙어 보이지 않게 한다.

## 메시지 입력창

- 브라우저의 수동 크기 조절 기능을 제거한다.
- 기본 한 줄 높이로 시작한다.
- 줄바꿈 또는 자동 줄바꿈으로 내용이 늘어날 때 `scrollHeight`에 맞춰 자동으로 높이를 늘린다.
- 최대 5줄까지 자동으로 늘어나며, 5줄을 넘으면 더 커지지 않고 입력창 내부에서 스크롤한다.
- 메시지 전송 후 입력창 높이를 기본값으로 되돌린다.
- `Enter`는 메시지를 전송하고 `Shift + Enter`는 줄바꿈한다.
- 한글 등 IME 조합 중의 `Enter`는 메시지를 전송하지 않고 글자 확정에만 사용한다.
- 공백뿐인 메시지는 키보드와 버튼 어느 방식으로도 전송하지 않는다.

## 테스트

- 입력 내용이 여러 줄이 되면 높이가 증가하고 5줄 높이에서 제한되는지 검증한다.
- 메시지 전송 후 입력값과 높이가 초기화되는지 검증한다.
- `Enter` 전송, `Shift + Enter` 줄바꿈, IME 조합 중 전송 방지를 각각 검증한다.
- 내 메시지와 상대 메시지에 서로 다른 클래스가 적용되는지 검증한다.
- 전체 프론트엔드 테스트와 프로덕션 빌드를 실행한다.

## 범위 제외

- 이미지·파일 메시지
- 메시지 수정·삭제
- 입력 중 표시
- 읽음 시각 및 개별 읽음 사용자 표시
