# 매칭 적합도와 알림 이동 개선 설계

## 목표

- 사용자가 매칭 점수를 100점 만점과 적합도 등급으로 이해할 수 있게 한다.
- 매칭 알림 카드 전체를 클릭하거나 키보드로 선택하면 해당 매칭 상세 화면으로 이동하게 한다.

## 적합도 계산

기존 가산 원점수의 의미는 유지하되, 평가 가능한 항목의 최대점만 분모에 포함해 0~100 정수로 환산한다. 기본 평가 항목은 대분류 25, 이름 30, 태그 20, 지역 10, 신뢰도 10점이다. 양쪽 세부 카테고리가 있을 때만 25점을, 양쪽 가치가 직접 입력된 경우에만 20점을 분모와 점수에 포함한다. 환산은 반올림하며 100을 넘지 않는다.

등급은 85~100 `매우 높은 적합도`, 70~84 `높은 적합도`, 55~69 `보통 적합도`, 40~54 `낮은 적합도`, 0~39 `매우 낮은 적합도`로 표시한다. 매칭 후보 생성 기준 60점은 환산 점수를 기준으로 적용한다.

## 알림 이동

`referenceId`가 있는 매칭 알림은 카드 전체를 링크처럼 동작시킨다. 마우스 클릭과 Enter/Space 키 입력 시 읽지 않은 알림을 먼저 읽음 처리하고 `/matches/{referenceId}`로 이동한다. 읽음 처리 API가 실패하면 이동하지 않고 오류를 표시한다. 카드 내부의 읽음 처리 버튼은 이벤트 전파를 막아 이동 없이 읽음 처리만 한다.

`referenceId`가 없는 과거 알림은 이동할 수 없으므로 일반 카드로 표시한다. 백엔드를 재시작하고 매칭을 다시 실행하면 기존 후보에도 연결 ID가 있는 알림이 생성된다.

## 검증

- 점수 계산 단위 테스트로 100점 상한, 선택 항목 분모 제외, 등급 경계값을 검증한다.
- 알림 화면 테스트로 카드 클릭, 키보드 이동, 읽음 전용 버튼의 이동 방지를 검증한다.
- 프론트 전체 테스트·빌드와 백엔드 전체 테스트를 실행한다.
